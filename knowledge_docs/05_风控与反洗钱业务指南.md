# 风控与反洗钱业务指南

## 一、风险管理体系

本平台建立了多层次风险管理体系，覆盖客户、产品和事件三个维度：

### 风险等级体系
平台使用统一的风险等级维表（dim_risk_level），分为三种类型：

- **客户风险等级（customer）**：根据客户信用状况、收入水平、资产规模等评定
- **产品风险等级（product）**：理财产品和贷款产品的固有风险
- **事件风险等级（event）**：风控事件和风险交易的严重程度

风险等级从低到高：R1（低）→ R2（中低）→ R3（中）→ R4（中高）→ R5（高）

## 二、风控规则与策略

### 风控策略（risk_strategy）
平台配置了多种风控策略，适用于不同业务场景：

1. **反欺诈策略**：适用于交易、开户、贷款申请
   - 检测异常交易模式
   - 识别虚假身份信息
   - 检测设备指纹异常

2. **反洗钱策略**：适用于大额交易、跨境转账
   - 大额交易报告（单笔 > 50,000 元）
   - 可疑交易识别
   - 资金来源追溯

3. **信贷准入策略**：适用于贷款申请
   - 负债收入比校验
   - 征信记录检查
   - 黑名单检查

4. **交易监控策略**：适用于日常交易
   - 频繁交易检测
   - 异常时间交易检测
   - 异常地点交易检测

### 风控规则（risk_rule）
每个策略下配置多条规则，规则包含：

- **规则表达式（rule_expression）**：定义触发条件
- **阈值（threshold_value）**：触发阈值
- **决策动作（decision_action）**：
  - **pass**：放行
  - **manual_review**：转人工复核
  - **reject**：拒绝
  - **block**：阻断并冻结

### 规则执行流程
1. 业务触发风控事件（risk_event）
2. 系统按策略编排执行规则
3. 命中的规则记录到 risk_hit_record
4. 根据规则决策动作执行后续流程
5. 需要人工复核的生成 manual_review_task

## 三、黑名单管理

### 黑名单类型（blacklist_record）
- **客户黑名单**：客户号维度，限制办理所有业务
- **证件黑名单**：身份证/护照维度，限制开户
- **手机号黑名单**：手机号维度，限制注册
- **账户黑名单**：账户号维度，限制交易
- **设备黑名单**：设备指纹维度，限制登录

### 黑名单处理
- **加入黑名单**：由风控事件触发或人工操作，需指定风险等级和原因
- **有效期**：可设永久或限期
- **移除黑名单**：需人工审批，记录移除原因
- **影响**：黑名单客户不能开户、贷款、理财，存量账户被冻结

## 四、反洗钱管理

### 可疑交易识别
以下交易模式会触发反洗钱调查：

1. **拆分交易**：将大额交易拆分为多笔小额交易规避报告
2. **快进快出**：资金快速转入转出
3. **频繁交易**：短时间内频繁大额交易
4. **跨账户归集**：多账户资金向单一账户归集
5. **异常时间交易**：非营业时间大额交易

### AML 案件流程（aml_case）
1. 系统自动或人工创建 AML 案件
2. 收集涉案交易（aml_case_transaction）
3. 风控人员进行初步审查
4. 复核人员审查并出具意见（aml_review_result）
5. 确认为可疑交易的，报送可疑交易报告（suspicious_transaction_report）
6. 案件结案或继续调查

### 可疑交易报告
- 报告类型：大额交易报告、可疑交易报告
- 报送时限：确认后 5 个工作日内
- 报告内容：涉案客户信息、交易明细、可疑原因分析
- 报送状态：待报送 → 已报送 → 已受理

## 五、人工复核

### 复核任务类型（manual_review_task）
- **风控复核**：风险事件需要人工判断
- **信贷审批**：贷款申请人工审批
- **理财适当性**：客户风险等级与产品不匹配时的例外审批
- **黑名单移除**：黑名单解除审批
- **大额交易**：超过自动审批额度的大额交易

### 复核流程
1. 系统生成复核任务，分配给对应角色员工
2. 员工查看风险事件详情和命中规则
3. 员工出具复核结论（通过/拒绝/待定）
4. 复核结论反馈到业务系统
5. 触发后续业务流程（如放行或拒绝）

## 六、催收管理

### 逾期等级
- **M1（1-30天）**：短信/电话提醒
- **M2（31-60天）**：人工电话催收
- **M3（61-90天）**：外访催收
- **M4（91-180天）**：法务介入
- **M5（180天以上）**：诉讼/核销

### 催收流程
1. 逾期记录生成（overdue_record）
2. 创建催收案件（collection_case），分配催收员
3. 催收员执行催收动作（collection_action）
4. 记录联系结果（collection_contact_record）
5. 客户可承诺还款（repayment_promise）
6. 还款到账后结清案件
7. 无法回收的进入核销（loan_write_off）或重组（loan_restructure）
8. 严重案件进入法诉（legal_case）

## 七、风险提示话术

### 常见风险提示
- "您的账户近期有异常交易，建议修改密码"
- "您的大额交易需要额外验证，请配合完成身份确认"
- "您的贷款已逾期，请尽快还款以免影响信用记录"
- "您购买的产品风险等级高于您的风险承受能力，请确认是否继续"
- "您的账户因安全原因被临时冻结，请联系客服处理"
