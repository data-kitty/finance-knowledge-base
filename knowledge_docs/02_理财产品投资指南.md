# 理财产品投资指南

## 一、理财产品类型

本平台提供以下类型的理财产品：

### 1. 固定收益类
- **特点**：投资于债券、存款等固定收益资产，预期收益稳定
- **风险等级**：R2（中低风险）
- **预期收益率**：3.0% - 5.0%
- **起购金额**：1,000 元
- **适合人群**：稳健型投资者，追求稳定收益

### 2. 混合类
- **特点**：投资于债券和股票等多种资产，收益和风险适中
- **风险等级**：R3（中等风险）
- **预期收益率**：5.0% - 8.0%
- **起购金额**：5,000 元
- **适合人群**：平衡型投资者，愿意承担一定风险追求较高收益

### 3. 权益类
- **特点**：主要投资于股票等权益资产，收益波动较大
- **风险等级**：R4（中高风险）
- **预期收益率**：8.0% - 15.0%
- **起购金额**：10,000 元
- **适合人群**：进取型投资者，能承受较大波动

### 4. 净值型理财
- **特点**：每日公布净值，收益随市场波动
- **运作模式**：开放式（随时申赎）或定期开放式（开放期申赎）
- **信息披露**：每日更新单位净值和累计净值

## 二、风险等级说明

本平台理财产品风险等级分为五档：

| 等级 | 名称 | 说明 | 适合客户 |
|------|------|------|---------|
| R1 | 低风险 | 本金安全，收益稳定 | 保守型 |
| R2 | 中低风险 | 本金风险低，收益有小幅波动 | 稳健型 |
| R3 | 中等风险 | 本金有一定波动，收益波动较大 | 平衡型 |
| R4 | 中高风险 | 本金波动较大，收益波动大 | 进取型 |
| R5 | 高风险 | 本金损失风险高，收益波动很大 | 激进型 |

## 三、适当性管理

客户购买理财产品前，必须完成风险测评（customer_risk_assessment）：

1. **风险测评**：客户填写风险承受能力测评问卷，系统计算评分
2. **等级匹配**：客户风险等级必须 ≥ 产品风险等级才能购买
3. **测评有效期**：风险测评有效期 12 个月，过期需重新测评
4. **超限购买**：客户风险等级低于产品等级时，系统拒绝购买并提示

## 四、申购与赎回流程

### 申购流程
1. 客户选择理财产品和申购金额
2. 系统校验：账户余额充足、适当性匹配、产品在开放期
3. 申购金额 ≥ 产品起购金额（min_purchase_amount）
4. 系统冻结申购资金（fund_freeze）
5. 确认日（T+1 或 T+2）确认份额和净值
6. 确认后扣除冻结资金，生成持仓（wealth_position）

### 赎回流程
1. 客户选择持仓和赎回份额
2. 系统校验：可用份额充足、产品在赎回开放期
3. 系统冻结赎回份额
4. 确认日确认赎回净值和到账金额
5. 资金到账日期根据产品清算规则确定（redeem_arrival_days）

## 五、净值与收益

### 净值类型
- **单位净值（unit_nav）**：每份理财产品的当前价值
- **累计净值（accumulated_nav）**：考虑分红再投资后的累计价值
- **日收益率（daily_yield_rate）**：当日收益率
- **年化收益率（annualized_yield_rate）**：折算到一年的收益率

### 收益计算
- **持有收益** = (当前净值 - 成本净值) × 持有份额
- **持仓市值（market_value_amount）** = 当前净值 × 持有份额
- **累计收益（accumulated_income_amount）** = 持仓市值 - 成本金额

### 收益分配
- **每日收益**：系统每日计算并记录收益（wealth_income）
- **收益结转**：定期将累计收益结转到客户账户
- **分红方式**：现金分红或红利再投资

## 六、产品开放期

理财产品根据运作模式分为：

### 开放式
- 每个工作日可申购和赎回
- 净值每日更新
- 资金流动性好

### 定期开放式
- 设有固定的申购开放期和赎回开放期（wealth_open_period）
- 开放期外不可申购和赎回
- 封闭期内净值仍每日更新

### 封闭式
- 存续期内不可赎回
- 到期自动清算并返还本息

## 七、清算规则

每只理财产品有清算规则（wealth_settlement_rule）：

- **申购确认天数（purchase_confirm_days）**：T+几确认申购份额
- **赎回确认天数（redeem_confirm_days）**：T+几确认赎回份额
- **赎回到账天数（redeem_arrival_days）**：赎回确认后几天资金到账
- **截单时间（cutoff_time）**：当日截单时间前的申请当日处理，之后次日处理
